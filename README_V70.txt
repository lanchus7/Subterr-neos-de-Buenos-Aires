V70 — Estado de líneas dinámico

Base: V69.

Ahora, para cada línea:
- Estado normal -> rayita verde + texto "Servicio normal"
- Con demora -> rayita naranja + texto "Servicio con demora"
- Interrumpida -> rayita roja + texto "Servicio interrumpido"
- Otros avisos -> gris + "Servicio con aviso"

La lógica se aplica tanto en desktop como en mobile y se actualiza con la respuesta del Worker.
