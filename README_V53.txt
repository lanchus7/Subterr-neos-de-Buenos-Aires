V53 — Origen/Destino realmente ordenados

Corrección sobre V51.

La lista desplegable real de Origen/Destino se genera desde la constante JavaScript STATIONS.
Ahora STATIONS está ordenada:
A → B → C → D → E → H → Premetro (P)

y dentro de cada línea, las estaciones siguen el orden de recorrido.

Las estaciones que pertenecen a más de una línea aparecen una sola vez, en la primera línea
en la que aparecen según ese orden, conservando todas sus bochitas de combinación.
